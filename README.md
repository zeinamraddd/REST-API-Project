# Notes REST API

## Project Description

A RESTful API built using Node.js, Express.js, and MongoDB. The API allows users to create, retrieve, update, and delete notes. All notes are stored persistently in a MongoDB database.

## Technologies Used

- Node.js
- Express.js
- MongoDB Atlas
- MongoDB Node.js Driver
- dotenv

## Installation and Setup

1. Clone or download the project.
2. Open the project folder in a terminal.
3. Install dependencies:

   `npm install`

4. Create a `.env` file containing:

   ```env
   MONGODB_URI=your_mongodb_connection_string
   PORT=3000
   ```

5. Start the server:

   `npm run dev`

6. The API will run at `http://127.0.0.1:3000`.

## API Endpoints

| Method | Endpoint | Description |
|---|---|---|
| GET | `/api/notes` | Retrieve all notes |
| GET | `/api/notes/:id` | Retrieve a specific note |
| POST | `/api/notes` | Create a new note |
| PUT | `/api/notes/:id` | Replace a note's editable fields |
| PATCH | `/api/notes/:id` | Partially update a note |
| DELETE | `/api/notes/:id` | Delete a note |

## Note Structure

Example note:

```json
{
  "_id": "690f123456789abcdef01234",
  "title": "Study Web Programming",
  "body": "Finish Assignment 6",
  "createdAt": "2026-11-07T15:00:00.000Z"
}
```

The `_id` is generated by MongoDB, and `createdAt` is generated when the note is created.

## Example POST Request

**Endpoint:** `POST /api/notes`

**Request body:**

```json
{
  "title": "My First Note",
  "body": "This is a test note"
}
```

**Successful response:** HTTP `201 Created`

## HTTP Status Codes

| Status | Meaning |
|---|---|
| 200 | Successful request |
| 201 | Note created |
| 204 | Note deleted successfully |
| 400 | Invalid request or input |
| 404 | Note not found |
| 500 | Internal server error |

## Validation and Error Handling

- A note must have a non-empty title.
- The body must be a string when provided.
- PUT requires both a valid title and body.
- PATCH requires at least one editable field.
- Invalid MongoDB IDs return status 400.
- Notes that do not exist return status 404.
- Unexpected database errors return status 500.

## Database Persistence

Notes are stored in the MongoDB `notesdb` database, inside the `notes` collection. They remain available after the Express server restarts.

## Security

MongoDB credentials are stored in a `.env` file. This file is excluded from Git using `.gitignore`.
